# Inbox: drop things here for the video agent

| Folder / file | What to put in it |
|---|---|
| `metrics/` | **Screenshots** of Instagram or YouTube insights for any video (the agent reads the numbers from the image). Name them anything; putting the video name in the filename helps, e.g. `tell-your-future-insta.png`. |
| `metrics/video-performance.md` | Or type the numbers in by hand. Any field you don't know, leave blank. |
| `audio/` | Voiceover files. Name the file after the video (e.g. `tell-your-future.mp3`), or anything else and the agent will match it to the script that is waiting for audio. |

The agent moves processed files into `inbox/processed/` so you can see what it already read.
