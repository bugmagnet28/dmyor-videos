# Content performance analytics

How every reel and post performs on every platform, kept as plain files: CSV for numbers, Markdown + PNG charts for people.
**Start with [`reports/OVERALL.md`](reports/OVERALL.md).**

## Layout

```
analytics/
├── README.md                 you are here
├── METRICS.md                what we measure, how posts are judged (48h checkpoint, traction score)
├── catalog/
│   └── content.csv           one row per posted piece per platform: url, posted time, style, hook type, topic, voice, length...
├── daily/
│   └── YYYY-MM-DD/           one folder per collection day
│       ├── SUMMARY.md        human-readable report of that day (auto)
│       ├── account.csv       followers / posts per platform
│       ├── instagram.csv     one row per post measured that day
│       ├── youtube.csv
│       ├── x.csv
│       └── raw/              optional: insight screenshots used for that day
├── reports/                  all auto-generated by scripts/build.py
│   ├── OVERALL.md            headline, "are we improving?", charts, leaderboard, data gaps
│   ├── WHAT_WORKED.md        trait-by-trait comparison (style, hook, topic, length, hour, narrated)
│   ├── latest_by_post.csv    every post in one table (latest + 48h + traction)
│   └── charts/*.png          followers, reach at 48h by post (progress), by style/hook/topic/hour, engagement rates
└── scripts/
    ├── record.py             the only way to write data (content / metrics / account / batch)
    └── build.py              rebuilds every SUMMARY.md, report and chart
```

Raw files are never edited by hand except to fix a mistake; reports are never edited at all (they are overwritten).

## Daily routine (agent or person)

1. **Register** anything newly posted (once per platform), right after posting or scheduling:
   `python3 analytics/scripts/record.py content --platform instagram --slug <slug> --url <url> --posted "YYYY-MM-DD HH:MM" --style <skill/style> --hook-type <type> --topic <topic> --narrated yes|no --voice <voice> --length <s>`
2. **Measure** posts that are about 24 h, 48 h and 7 days old (the 48 h reading matters most):
   `python3 analytics/scripts/record.py metrics --platform instagram --slug <slug> --captured "YYYY-MM-DD HH:MM" --views .. --reach .. ... --source <where>`
   and the follower count once a day: `record.py account --platform instagram --followers N --posts N --captured ...`
3. **Rebuild**: `analytics/.venv/bin/python analytics/scripts/build.py`, then the one-page chart `analytics/.venv/bin/python analytics/scripts/dashboard.py` (writes `reports/charts/DASHBOARD.png`)
4. **Read** `reports/OVERALL.md` and `reports/WHAT_WORKED.md`; write conclusions into `studio/learnings.md` / `studio/playbook.md`.

First-time setup of the chart environment: `python3 -m venv analytics/.venv && analytics/.venv/bin/pip install matplotlib`.

## Where numbers come from (and safety)

| Platform | Best source | Notes |
|---|---|---|
| Instagram | Sanyam's app insight screenshots (`daily/<date>/raw/`) for watch time + skip rate; profile Reels grid for views | **Do not load many insight pages from the browser**: the account was locked on 2026-10-22 after heavy automated activity. One grid read per day is fine. |
| YouTube | Studio → Content → Shorts list (views), each Short's Analytics tab (avg view duration, % viewed, stayed-to-watch) | |
| X | Post analytics (impressions, engagements, link clicks, profile visits) | Replies/engagement actions are logged in `Dmyor/growth/x/engagement-log.md`, not here. |

Never fabricate. A missing number stays empty. Saves made by our own account go in `self_saves` so they are excluded.

## Vocabulary for traits (catalog)

- `style`: the video skill / production type, e.g. `kinetic-typography`, `diagram-motion-graphics`, `app-screen-demo`, `illustrated-scene` (retired).
- `hook_type`: `hard-truth`, `question`, `number-fact`, `number-contrast`, `framework-list`, `quiz`, `fill-in-the-blank`, `reassurance-flip` (add new ones as needed; keep names short and reuse them).
- `topic`: `procrastination`, `planning`, `goal-setting`, `habits`, `consistency`, `focus`, `time`, `motivation`.
Consistent labels are what make WHAT_WORKED.md meaningful.
