# life-in-weeks (15.2s, no VO, on-screen text only)

Openings considered:
1. "A long life is about 4,000 weeks." (chosen: a number the viewer can check, frame-0 readable, sets up the grid)
2. "You've already used 1,300 weeks." (assumes the viewer's age; wrong for most)
3. "Every box is one week of your life." (needs the grid on frame 0; too small to read as a cover)

On screen:
- 0.0  A long life / is about / 4,000 / weeks.
- 1.75 80 years. / 1 box = 1 week.   (80 x 52 grid draws in)
- 3.3  By age 25: / 1,300 gone.      (first 25 columns turn coral)
- 5.0  Still left: / 2,860.          (rest turn green)
- 6.6  You can't plan / 2,860 weeks. (struck out)
- 8.2  You can plan / this one.      (all boxes dim, one grows blue)
- 9.95 Pick one / goal. / Give it / this week.
- 11.5 Send this / to someone / waiting for / next year.
- 13.0 dmyor / Turn a big goal into a daily plan. / @dmyor_global

Math: 80 x 52 = 4,160 (exact 80 x 52.18 = 4,174, shown as "about 4,000"). 25 x 52 = 1,300. 4,160 - 1,300 = 2,860.
